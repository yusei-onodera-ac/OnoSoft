# おのソフト ブランドガイド

小粒Windowsユーティリティを「シリーズ」として量産・配信するための、
最低限そろえておきたい共通ルール。

## シリーズ名

- 表示名: **おのソフト**
- 英語/ローマ字表記(リポジトリ名・ドメイン等で使用): `onosoft`
- 各アプリのウィンドウタイトルやタスクトレイのツールチップには、
  アプリ名の後に `(おのソフト)` を添える(例: 「クリップボード履歴マネージャー (おのソフト)」)。
  シリーズものだと一目でわかるようにするため。

## 配色(ダークテーマ、全アプリ共通)

`src/OnoSoft.Shared/Theme/AppTheme.xaml` と `BrandColors.cs` が単一の情報源。
新しい配色を追加したくなったら、まずこの2ファイルを更新してから各アプリに反映する。

| 用途 | 色 |
|---|---|
| 背景 (Background) | `#1E1F26` |
| パネル (Panel) | `#2A2B36` |
| アクセント (Accent) | `#5B8CFF` |
| 本文テキスト (Text) | `#F0F1F5` |
| 補助テキスト (SubText) | `#9A9CAC` |
| ホバー (Hover) | `#353748` |
| 枠線 (Border) | `#3A3C4A` |

## アイコン

- 通常は `OnoSoft.Shared.Tray.IconFactory.CreateGlyphIcon("X")` で、
  角丸のアクセントカラー正方形+1文字グリフのアイコンを実行時生成する。
  外部の .ico ファイルを用意する手間を省き、シリーズ全体で統一感を出すため。
- グリフ文字はアプリ名の頭文字を基本とする(クリップボード履歴マネージャー → `C`)。
  重複する場合は2文字目や象徴的な文字を検討する。
- 将来的に手描きロゴを用意する場合も、背景の角丸+アクセントカラーというフォーマットは踏襲する。

## 命名規則

- **アプリ名(日本語表示名)**: 「〇〇マネージャー」「〇〇トラッカー」など、機能が一目でわかる名前
- **リポジトリ名(英語)**: ケバブケース、機能をそのまま英訳(例: `clipboard-history-manager`)
- **アセンブリ名/名前空間**: パスカルケース(例: `ClipboardHistoryManager`)
- **バージョニング**: [Semantic Versioning](https://semver.org/lang/ja/) (`MAJOR.MINOR.PATCH`)。
  初回リリースは `1.0.0`。

## トーン

- 説明文・UIコピーは丁寧語(です・ます調)で統一。
- エラーメッセージは「何が起きたか」「どうすればよいか」を簡潔に。
- 広告や過度なテレメトリは入れない(フリーソフトとしての信頼感を優先)。
